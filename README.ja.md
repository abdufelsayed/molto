# Molto

Molto は Apple Silicon 上でローカル AI モデルを実行・管理します。1 つのコマンドで Web ダッシュボードと推論サーバーを起動し、同じ公開ポートを使用します。[oMLX](https://github.com/jundot/omlx) のフォークです。
