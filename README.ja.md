# oMLX

この翻訳は、macOS アプリと Web 管理画面を含む旧版について書かれています。現在の構成には対応していません。

このリポジトリには、単独で動作する推論サーバーと小規模な管理 REST API が含まれます。現在のインストール方法、コマンド、制限については[英語版 README](README.md)、[管理 API](docs/management-api.md)、[バックエンド構成](docs/backend-architecture.md)を参照してください。この版では英語の文書が正式な案内です。
