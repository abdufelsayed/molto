# oMLX

이 번역은 macOS 앱과 웹 관리자 화면이 포함된 이전 버전을 설명합니다. 현재 구성에는 맞지 않습니다.

이 저장소에는 독립 실행형 추론 서버와 작은 관리 REST API가 있습니다. 현재 설치 방법, 명령, 제한 사항은 [영문 README](README.md), [관리 API 문서](docs/management-api.md), [백엔드 구조](docs/backend-architecture.md)를 참고하세요. 이 버전에서는 영문 문서가 기준입니다.

라이선스는 [Apache 2.0](LICENSE)입니다. oMLX는 [vllm-mlx](https://github.com/waybarrios/vllm-mlx)를 바탕으로 시작했습니다.
