# Molto

Molto는 Apple Silicon에서 로컬 AI 모델을 실행하고 관리합니다. 하나의 명령으로 웹 대시보드와 추론 서버를 시작하며 동일한 공개 포트를 사용합니다. [oMLX](https://github.com/jundot/omlx)의 포크입니다.
